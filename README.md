# 🧩 思維拼圖 Thought Puzzle

一個幫助你**收集碎片想法，拼出完整思維**的瀏覽器工具。

## 功能

- **📝 輸入想法** — 寫下碎片想法，加上標籤和狀態分類
- **🧩 拼圖牆** — 卡片式瀏覽、篩選、搜尋所有碎片
- **💬 對話引導** — 4 種引導框架幫你展開思路：
  - 5W1H 全面提問法
  - SWOT 優勢劣勢機會威脅
  - 六頂思考帽多角度思考
  - 自由對話
- **📦 整併產出** — 選取多個碎片整併為 Markdown 文件
- 支援 JSON 匯入/匯出備份

## 使用方式

直接用瀏覽器開啟 `index.html` 即可使用，所有資料儲存在瀏覽器 `localStorage`。

## 技術

純前端 HTML + CSS + JavaScript，無需後端、無需安裝。

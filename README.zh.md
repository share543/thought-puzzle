# 🧩 思維拼圖

> 收集碎片想法，拼出完整思維。

[**English**](README.md)

一個在瀏覽器中直接執行的思維工具，幫助你捕捉、組織、連結、整合想法。無需伺服器、無需安裝。

---

## 功能

### 📝 輸入想法
寫下碎片想法，加上標籤和狀態分類（💡 靈感 / 🔍 待擴展 / ✅ 已完成）。

### 🧩 拼圖牆
卡片式瀏覽，按狀態或標籤篩選，全文搜尋，進度追蹤。

### 💬 對話引導 — 11 種思考框架

| 框架 | 適用場景 |
|------|----------|
| **5W1H 全面提問法** | 人事物時地為何如何，全面盤點 |
| **SWOT 優劣勢分析** | 優勢、劣勢、機會、威脅 |
| **六頂思考帽** | 白/紅/黑/黃/綠/藍 — 多角度思考 |
| **SCAMPER 創新發想** | 替代/結合/改編/修改/他用/刪減/重組 |
| **⚛️ 第一性原理** | 拆解到基本事實，從零重構 |
| **🔄 逆思維** | 反向假設、失敗預演，找出盲點 |
| **📐 金字塔原理** | 結論先行，MECE 邏輯架構 |
| **🎯 GROW 模型** | 目標 → 現況 → 選項 → 行動計畫 |
| **⚖️ PMI 利弊分析** | Plus / Minus / Interesting 三欄決策 |
| **自由對話** | 隨意問答，自由探索 |
| **🧠 全局分析** | 自動掃描所有碎片 → 發現主題叢集 → 引導擴展 |

### 🤖 LLM 強化功能（可選）

讓你的思維拼圖再升級！使用者自備 API 端點（BYOK，Bring Your Own Key），完全由你控制。

| 功能 | 演算法模式 | LLM 模式 |
|------|-----------|----------|
| **對話引導** | 固定模板問句 | LLM 讀取你的碎片與對話歷史 → 產生**個人化追問** |
| **思緒融合** | 詞頻統計 + 樣板拼接 | LLM 以你的碎片為素材，寫出**有邏輯有觀點的文章** |

**使用方式：**
1. 點右上角 ⚙️ 齒輪按鈕
2. 填入 API 端點、金鑰、模型名稱
3. 點**測試連線**確認設定正確
4. 開啟 LLM 功能並儲存

LLM 呼叫失敗時（網路問題、金鑰錯誤、逾時），會**自動降級**回演算法模式，絕不卡住你的工作流程。

#### 推薦的 API 服務

| 服務 | CORS 支援 | 說明 |
|------|-----------|------|
| [OpenRouter](https://openrouter.ai/) | ✅ 支援 | **預設推薦** — 瀏覽器直接可用，模型選擇多 |
| [Groq](https://console.groq.com/) | ✅ 支援 | 速度快，適合小型模型 |
| [Together AI](https://www.together.ai/) | ✅ 支援 | 模型選擇不錯 |
| Ollama (localhost) | ⚠️ 同源才可 | 網頁須透過本機 HTTP server 開啟（如 `python -m http.server`），不可用 HTTPS 或 `file://` |
| Ollama (外部 IP) | ⚠️ 同源才可 | 同上，或用反向代理解決 CORS |

> ⚠️ OpenAI / Anthropic 原生 API **不支援瀏覽器端 CORS**，請透過 OpenRouter 等代理服務使用。

所有設定僅存於瀏覽器 `localStorage`，不留程式碼、不送第三方伺服器（除了你指定的 API 端點）。

### 📦 思緒融合引擎

兩種模式：

**演算法模式**（預設，免設定）：
1. **關鍵詞萃取** — TF 式中文關鍵詞（過濾 80+ 停用詞）
2. **相似度矩陣** — Jaccard + 重疊率混合評分
3. **貪婪聚類** — 自動將相關碎片分群
4. **主題生成** — 從標籤與關鍵詞提煉各節主題
5. **敘事建構** — 導入段 → 交織內文 → 智慧橋接 → 總結 → 完整 Markdown

**LLM 模式**（設定啟用後）：
- 將碎片 + 整併指引送給 LLM，產出真正有流暢度的文章
- 自動降級：LLM 失敗時退回演算法模式

可選的**整併指引**輸入匡讓你指定輸出形式（如「部落格文章」「簡報大綱」「行動計畫」）。

### 💾 備份
JSON 匯入／匯出，資料完整攜帶。

## 使用方式

直接用瀏覽器打開 `index.html`，資料存在瀏覽器 `localStorage`。

## 技術

純前端 HTML + CSS + JavaScript (ES6)。零依賴、零後端。

LLM 客戶端使用標準 OpenAI-compatible `/v1/chat/completions` 介面，任何支援此格式的服務皆可使用。
